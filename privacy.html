Datenschutzerklärung

Stand: 16.11.2026

Zweck

Claude Kalender ist ein privates Werkzeug, das ausschließlich von seinem Ersteller für den eigenen Google-Kalender genutzt wird. Es gibt keine weiteren Nutzer.

Welche Daten verarbeitet werden

Mit Zustimmung des Nutzers greift die Anwendung über den Scope https://www.googleapis.com/auth/calendar auf Kalender, Termine und Geburtstage des eigenen Google-Kontos zu, um sie anzuzeigen, anzulegen, zu ändern oder zu löschen.

Speicherung und Weitergabe

  • Die Anwendung läuft lokal auf dem Rechner des Nutzers. Es gibt keinen eigenen Server.
  • Das OAuth-Token wird ausschließlich lokal im verschlüsselten Windows Credential Manager gespeichert.
  • Kalenderdaten werden nicht dauerhaft gespeichert, nicht verkauft und nicht für Werbung verwendet.
  • Kalenderdaten werden nur auf Anweisung des Nutzers an den von ihm selbst verwendeten KI-Assistenten übergeben.

Google API Services User Data Policy

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

Privacy Policy (English)

Claude Kalender is a private tool used only by its creator for their own Google Calendar. With the user's consent it accesses calendars, events and birthdays via the scope https://www.googleapis.com/auth/calendar to display, create, modify or delete them. It runs locally; there is no server. The OAuth token is stored only in the local, encrypted Windows Credential Manager. Calendar data is not stored persistently, not sold, not used for advertising and is passed only to the AI assistant the user chooses to use, at the user's request. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
